# `portal_learning` — материалы, чек-листы, квизы

> **Статус UI:** временно заморожен (пункт меню и SPA-маршрут `/learning` скрыты). API и SQLAdmin сохранены — не удалять пакет без решения о разморозке.

## Назначение

Модуль **обучения** в портале: учебные материалы, чек-листы с прогрессом пользователя, квизы (вопросы, попытки, проверка ответов). Админские вьюхи **SQLAdmin** вынесены в `admin/`. **Не** заменяет внешний LMS и **не** хранит внешние SCORM: только внутренняя модель `portal_learning` + RBAC, согласованный с порталом.

**Сквозные правила** (материалы и квизы — глобальные объекты портала, без привязки к разделам навигации) — [../MODULES.md](../MODULES.md). **Квиз** привязанный к **материалу** наследует ограничения по группам материала; квиз **без** `material_id` ведёт себя как остальные глобальные объекты (см. `MODULES`, раздел про квизы) — в README **не** переписываем, только отсылаем.

## HTTP

Роутер: [`router.py`](router.py), префикс **`/portal`**, маршруты в `routes/*` дают пути к **`/learning/...`**.

Сборка: `/api/v1/portal/learning/materials`, `.../learning/checklists/...`, `.../learning/quizzes/...` (точные пути — в декораторах `routes/*.py`).

**OpenAPI теги:** `Обучение · Материалы`, `Обучение · Чек-листы`, `Обучение · Тесты`.

## Карта пакета

| Путь | Содержимое |
|------|------------|
| `routes/materials.py` | Материалы: список, карточка, CRUD (группы Keycloak, статусы) |
| `routes/checklists.py` | Чек-листы: список, карточка, CRUD, прогресс, пункты, `my-progress` |
| `routes/quizzes.py` | Квизы, попытки, ответы |

| `admin/material.py`, `checklist.py`, `quiz.py` | SQLAdmin по сущностям; RU-подписи enum — из общего `app/admin/enum_labels.py` (не дублировать локально, ) |

## Вертикали (коротко)

- **Материалы** — тело, тип, статус, разграничение по **группам Keycloak** (M2M `PortalLearningMaterialIdpGroup.idp_group`, список `idp_groups` в API); пустой список = видно всем.
- **Чек-листы** — структура, старт, отметка пунктов, **прогресс** пользователя; разграничение по **одной** группе Keycloak (`idp_group`), пустая строка = для всех.
- **Квизы** — вопросы, прохождение, **попытки**; логически связаны с материалом для согласованного RBAC (тест без `material_id` виден всем, тест с `material_id` наследует видимость материала).

## RBAC: группы Keycloak (IdP), не `PortalRole`

Видимость материалов и чек-листов строится **исключительно на группах Keycloak из токена** (`user.idp_groups`, известные значения — `app.core.auth_constants.IDP_KNOWN_PORTAL_GROUPS`), а не на легаси-концепции `PortalRole`/`nav_node` — та полностью удалена из проекта (см. коммит `693c471`). `is_portal_admin` видит всё независимо от групп и статуса (черновик/архив).

## Зависимости

- **`app.infrastructure.db.models.portal_learning`**
- **`app.core.auth_constants`** (`IDP_KNOWN_PORTAL_GROUPS`) — известные группы Keycloak для материалов и чек-листов

- Другие `portal_*` — по минимуму (только то, что реально импортируется в сервисах; в основном домен автономен)
