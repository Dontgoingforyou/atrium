# Доменные чеклисты тестов

Конкретные контракты по доменам и инфраструктуре: что закрывать HTTP/юнитом, какие файлы, какие кейсы. Вынесено из `.cursor/rules/testing.mdc` (там остались только принципы: пирамида, TDD, граница тестов, организация, ассерты, покрытие). Этот файл — справочник для ревью и онбординга, не cursor-rule.

Общие принципы (граница тестов, запрет coverage-файлов, `dependency_overrides.clear()`, параллелизм, ассерты) — в [`.cursor/rules/testing.mdc`](../.cursor/rules/testing.mdc). При конфликте принципов и конкретного чеклиста — принцип приоритетнее.

## Инфраструктура

- **WS-тикеты**: второй `consume` → `None` (memory и Redis/`getdel`); Redis `set(..., ex=TICKET_TTL_SEC)`; чужой prefix → `None`. Писать в `_mem_store` только с полным prefix; не тестировать мёртвые `_key()`.
- **Keepalive**: публичные `ws_keepalive` + `is_pong`; обязателен путь «pong предотвращает close»; запрет sleep-only без ассерта эффекта.
- **Storage** (`storage/client.py`): presign default TTL из Settings; `force_download` + filename; `download_object_bytes` закрывает response; `delete_objects` — ошибка не только на первом батче.
- **Jobs** (`app/jobs/`): disabled → `assert_not_awaited` сервиса, **без** заранее `stop.set()`; exception итерации — вторая итерация (`await_count == 2`), не `stop.set()` на первой ошибке; `stop` во время wait — без purge; calendar `max(15, interval)` в `wait_for`; `*_hour_utc` доходит до `seconds_until_next_run_utc`. Доменный purge/reminders не копировать в `tests/jobs/`.

## Интеграции

- **Jira webhook** (`POST /integrations/jira/webhook`): 403/400 — `status` + `code`; пустой секрет fail-closed; секрет той же длины но другой; нет заголовка; `ValidationError` → 204. Один HTTP-набор в `tests/integrations/jira/`; в `portal_specialists` — только реальный apply (unlinked 204, debounce), не дубль happy-path с моком.
- **Jira write** (`write_client.py`): `add_watcher` 4xx не бросает; `find_user_by_email` — точный email case-insensitive, 4xx/не-list → `None`; create/update/transition/comment/attachment 4xx → 503; update 404 → `NotFoundError`; JSON не того типа → 503. Read-клиент: JSON не dict → 503.
- **Jira-ссылки**: публичный `is_http_url` + `extract_link_urls` — `javascript:` / `data:` / `ftp:` / URL без host не проходят. Приватные `_format_*` normalize — только через `extract_jira_field_text`.
- **EA photo client**: disabled; сеть → 503; photo 404 → `NotFoundError`; magic bytes; лимит без `Content-Length`; charset в CT; upload 422; delete 404 ok; quote username с не-ASCII/`/`. `hmac_secrets_equal` — в `tests/core/`, не в integrations.

## Доменные HTTP-чеклисты

### Calendar HTTP

`status` + `code`; 401-матрица включая event/attendees/overrides и calendar-by-id (invites accept — optional auth, не 401). Timesheet — фикстура `client_developer`, не `dependency_overrides.clear()`. Owner-only settings/delete calendar; viewer/attendee не пишут attendees/overrides. Удалённый календарь → 404, не 403|404. Peer-view: unknown `user_sub` → 404; пусто без календарей коллеги; replace не overlay; write 403; peer-view: attendee-события коллеги только если viewer сам имеет доступ; чужой `calendar_id` в `/occurrences` — silent drop. Search: title+description+location; ILIKE escape `%`/`_`. WS: HTTP ticket + TestClient; не звать `calendar_websocket` / `create_calendar_ws_ticket` напрямую; payload invalidate-only (`type`/`actor_sub`/ids, без title); timesheet на WS — публичный `issue_calendar_ws_ticket` + close 4001. Reminders: публичный `process_due_reminders`; invalid RRULE skip; grace 5 мин; recurring occ; точный count; SMTP fail не маркирует email; не копировать job-цикл и XSS письма.
